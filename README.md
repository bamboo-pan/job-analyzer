# job-analysis
## 1.大致原理
通过从招聘网站提取职位信息，并对职位信息进行深入比对，筛选出符合预期的岗位，比较项包括通勤时间，公司口碑等  
## 2.细节  
  a.从51job根据关键字及搜索条件获取职位信息  
  b.获取每一个职位对应公司的实际地址  
  c.通过百度地图API以及高德地图API计算出通勤时间，两者取最小的  
  d.通过看准网获取公司口碑  
  e.最终结果保存到excel  
  g.可选择使用代理

  >>我自用的是阿里云API创建虚拟机，创建代理服务器,用完释放虚拟机，感兴趣可自行研究
